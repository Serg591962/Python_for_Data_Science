##### **Библиотека SciPy** - это мощное расширение NumPy, которое предоставляет набор подмодулей для научных и инженерных вычислений. 
Она особенно полезна в Data Science и включает инструменты для:
- Оптимизации (scipy.optimize)
- Линейной алгебры (scipy.linalg)
- Обработки сигналов и изображений (scipy.signal, scipy.ndimage)
- Преобразований Фурье (scipy.fft)
- Специальных математических функций (scipy.special)
- Статистики (scipy.stats)
- Утилит и изображений (scipy.misc)
Три главных подмодуля:
- scipy.misc — содержит полезные утилиты, например, для загрузки изображений (в новых версиях уже неактуально).
- scipy.special — предоставляет доступ к специальным функциям (гамма-функция, бета-функция и т.д.).
- scipy.stats — мощный инструмент для работы со статистикой, вероятностями и распределениями.
**Библиотека matplotlib.** 
Она позволяет визуализировать разные типы графиков, диаграмм и изображений. По соглашению для импорта библиотеки построения графиков ее нужно импортировать с именем plt: import matplotlib.pyplot as plt
###### **Подмодуль scipy.misc**
**from scipy import misc** - содержит тестовые изображения (face и ascent)
**import matplotlib.pyplot as plt** - для отображения изображений и графиков.
**print("Старт скрипта")** - выводит в консоль сообщение, что скрипт начал работу.
**Цветное изображение (ёж на траве)**
**face = misc.face()** - - Вызывает функцию `face()` из модуля `misc`
- Эта функция загружает встроенное цветное изображение
- Возвращает его как массив (768, 1024, 3)
- Сохраняет этот массив в переменной `face`
**plt.imshow(face)** - функция из matplotlib, которая рисует это цветное изображение.
**plt.title("Цветное изображение: scipy.misc.face()")** - задаёт заголовок окна с изображением
**plt.axis('off')** - отключает отображение осей координат вокруг изображения 
**plt.show()** - открывает окно с изображением. Важно: после вызова `plt.show()` программа ждёт, пока окно не будет закрыто вручную. Пока окно открыто, скрипт «приостановлен».

**Чёрно-белое изображение (текстура гор)**
ascent = misc.ascent() - загружает другое тестовое изображение, но в оттенках серого (одно значение яркости на пиксель). Сохраняет массив в переменной ascent
plt.imshow(ascent, cmap='gray') - отображает это изображение с цветовой картой `'gray'`, чтобы показать оттенки серого.
plt.title("Чёрно-белое изображение: scipy.misc.ascent()")
plt.axis('off')  
plt.show() - открывает окно с чёрно-белым изображением, ждет закрытия.
