###### **Два основных понятия в matplotlib — это фигуры и оси:**
фигуры - это весь экран компьютера.
оси - часть экрана на которой строятся графики 
- FigureВсё полотно         (общее окно)	                                         fig, ax = plt.subplots()
- Axes	                                Область, где рисуется один график	ax.plot(...)
- Axis	                                Конкретная координатная ось (X или Y)
**Для создания фигур и осей** matplotlib предлагает два подхода: **явный и неявный.** 
**Неявный стиль** 
`plt.plot([1, 2, 3], [1, 4, 9])` - Построение первого графика: x-значения: [1, 2, 3] y-значения: [1, 4, 9]
matplotlib сам создаёт фигуру и ось,
`plt.plot([1, 2, 3], [9, 4, 1])` 
plt.title("Неявный") - Добавляет заголовок к текущему графику
plt.show() - Показывает окно с графиком
**Явный стиль**
fig, (ax1, ax2) = plt.subplots(1, 2)
- fig — это фигура (большой холст)  
- ax - это одна ось (область для рисования) (определяем что их будет две и их названия)
- plt - это сокращение для модуля `matplotlib.pyplot`.
- plt.subplots() — это функция, которая создаёт: fig, axes
- (1, 2) - получаем график в 1 строку и 2 столбца
`ax1.plot([1, 2, 3], [1, 4, 9])` - рисуем первый график **на первой оси (`ax1`)**
`ax2.plot([1, 2, 3], [9, 4, 1])`
ax1.set_title("первый") - это установка заголовка для конкретной оси (графика).
plt.show() - это команда вывести график на экран
###### 1. **Метод plt.plot - построение линейного графика**
import matplotlib.pyplot as plt
`X = [0, 1, 2, 3, 4, 5, 7, 8, 9, 10]`
`Y = [20, 25, 35, 50, 10, 12, 20, 40, 70, 110]`

plt.show() # Команда вывести график на экран
###### 2. **Метод plt.hist - строит гистограмму, график распределения данных по интервалам (бинам)**
import matplotlib.pyplot as plt
X = [0, 1, 2, 3, 4, 5, 7, 8, 9, 10]
Y = [20, 25, 35, 50, 10, 12, 20, 40, 70, 110]
plt.bar(X, Y, width=0.8, align='center')  # Построит столбчатую диаграмму
plt.title("Гистограмма с заданными значениями и частотами")
plt.xlabel("Значение")
plt.ylabel("Частота")
plt.show()
**Функция plt.bar()**
plt.bar() — это метод для построения столбчатых диаграмм (bar charts).
параметры имеют определённый порядок, то есть позиционные аргументы:plt.bar(x, height, ...)
X — координаты столбцов по горизонтальной оси (где рисовать столбцы).
Y — значения для параметра height. height — высоты столбцов (как высокие будут столбцы, обычно это частоты или значения).
width — ширина каждого столбца (по умолчанию равна 0.8). Если width=1, тогда каждый столбец занимает всю ширину между двумя целочисленными точками.
align — выравнивание столбцов относительно координат x.

##### **- Использование аргумента fmt.**  
Это позиционный параметр, который отображается справа от параметра Y. Он состоит из форматирующей строки, использующей условное обозначение для настроек маркера, стиля линии и цвета. 
X = [0, 1, 2, 3, 4, 5, 7, 8, 9, 10] 
Y = [20, 25, 35, 50, 10, 12, 20, 40, 70, 110] 
fmt = 's-.r' (s квадрат, -. стиль штрих-пунктир (dash-dot), r красный  )
plt.plot(X, Y, fmt)
можно добавить linewidth=4.3 - ширина линии в графике, измеряется в пунктах (points), где 1.0 — это стандартная толщина.
fmt = 's-.r' 
plt.plot(X, Y, fmt, linewidth=4.3)
